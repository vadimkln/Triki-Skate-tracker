# Своя модель дошки

Поклади сюди файл `board.glb` — сайт підхопить його сам замість стандартної дошки.

- Формат: **.glb** (усе в одному файлі, текстури всередині).
- Орієнтація: ніс дошки вздовж осі **+X**, верх — **+Y**. Розмір не важливий — модель масштабується до ~80 см.
- Якщо модель дивиться не в той бік, створи поруч `board.json` з поворотом навколо вертикалі, напр. `{"rotateY": 90}`.
- Бажано до 5–10 МБ і без зайвих деталей, щоб на телефоні не гальмувало.
