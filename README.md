# Triki Skate

Сайт для датчика Triki від Żabka. Два режими:
- **Трекер** — Triki на скейті: розпізнавання трюків, 3D-повтор з таймлайном, статистика сесії.
- **Гра** — Triki в руці як фінгерборд: трюк розпізнається за жестом, дошка на екрані показує його, рахунок, комбо, S.K.A.T.E.

Мови: українська, англійська, польська (за мовою телефона, перемикач у налаштуваннях).
Працює в браузері Bluefy на iPhone або в Chrome/Edge на комп'ютері. Сайт має відкриватись через https (GitHub Pages це дає).

## Структура
- `index.html`, `css/app.css` — розмітка і стилі
- `js/main.js` — запуск, з'єднує модулі, перемикач режимів
- `js/i18n.js` — усі тексти трьома мовами
- `js/ble.js` — Bluetooth: список усіх пристроїв, збережений Triki, автопідключення
- `js/sensor.js` — розбір пакетів, осі дошки, орієнтація, калібрування спокою
- `js/tricks.js` — пошук і розпізнавання трюків на дошці (налаштовано за записами реальних трюків: на місці, на ходу, фліпи, їзда по рівному й нерівному); тут же автоматичне уточнення положення Triki за попами й фліпами
- `js/replay.js`, `js/viewer.js` — побудова повтору й екран повтору з таймлайном
- `js/game.js`, `js/gameui.js` — гра: розпізнавання жестів, очки, S.K.A.T.E., екран гри
- `js/session.js` — сесія, статистика, історія
- `js/scene.js` — 3D-сцена, фізика (гравітація, тверда підлога), відтворення повторів
- `js/board.js`, `js/textures.js` — модель дошки й текстури асфальту
- `js/demo.js` — демо без Triki (трекер і гра), анімації трюків для гри
- `js/ui.js`, `js/gps.js`, `js/math.js`, `js/util.js`
- `vendor/` — three.js r160 (без CDN)
- `models/` — сюди можна покласти свою модель `board.glb`

## Як розпізнаються трюки
- **Поп** — удар хвостом від 2,6 g, після якого дошка одразу крутиться (задирає ніс). Ями, бордюри й асфальт дають удари до 4 g, але без такого обертання.
- **Політ** — колеса не тримаються за землю: сила вздовж «верху» дошки майже нуль або від'ємна (ноги притискають дошку зверху), і дошка крутиться.
- **Приземлення** — найсильніший удар знизу в пачці ударів, після якого дошка за третину секунди перестає крутитись і стоїть на колесах.
- Крок часу береться зі справжнього часу приходу кожного виміру: телефон приносить 10–25 вимірів на секунду нерівно, пачками й з дірками.
- Зсунуті пакети (числа по колу на кілька місць) відкидаються — вони виглядали як фальшивий поп.
- Якщо Triki переставили на дошці, а майстер положення не пройшли, програма сама уточнить, куди дивиться ніс, після кількох оллі або першого фліпу.

## Оновлення на GitHub Pages
Сторінка завантажує один файл `app.js` (усі модулі з `js/`, зібрані разом). Його адреса містить версію (`app.js?v=…`), тож телефон не змішує старі файли з кешу з новими. Папки `js/` і `vendor/` — вихідний код, сторінка їх напряму не використовує.
1. Розпакуй архів.
2. У репозиторії: Add file → Upload files.
3. Перетягни **вміст** папки (`index.html`, `app.js`, `README.md`, `css`, `js`, `models`, `vendor`) — не саму папку. Найважливіші — `index.html` і `app.js`.
4. Commit changes. Сайт оновиться приблизно за хвилину; у Bluefy онови сторінку (GitHub може ще до 10 хвилин віддавати стару `index.html`).
5. Перевір версію: Налаштування → Діагностика → «Версія сайту».
6. Файл `js/calib.js` з давньої версії більше не потрібен — його можна видалити.
