# Triki Skate

Сайт для датчика Triki від Żabka. Два режими:
- **Трекер** — Triki на скейті: розпізнавання трюків, 3D-повтор з таймлайном, статистика сесії.
- **Гра** — Triki в руці як фінгерборд: трюк розпізнається за жестом, дошка на екрані показує його, рахунок, комбо, S.K.A.T.E.

Мови: українська, англійська, польська (за мовою телефона, перемикач у налаштуваннях).
Працює в браузері Bluefy на iPhone або в Chrome/Edge на комп'ютері. Сайт має відкриватись через https (GitHub Pages це дає).
